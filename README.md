# Reverie 🌙

A romantic roleplay social platform where you can create characters, share stories, and chat with AI companions.

## Features
✨ Character Creation
💬 Smart Chat with Memory
📖 Story Sharing
🔐 18+ Verified Community
⚡ Gradual Relationship Development

## Quick Start
1. npm install
2. Create .env file
3. npm start

## Deploy FREE
- Backend: Railway or Render
- Database: MongoDB Atlas (free tier)
- Frontend: Vercel
